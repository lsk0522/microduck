# 조립 가이드 검증 기록 (2026-10-30)

대상: `Microduck_Assembly_Guide.pdf` (트랙 A, 원본 형상), 나사 126개.
방법: 가이드를 만든 계산(`find_screws.py`, 구멍 지름·깊이 규칙)과 **다른 방법**으로 다시 확인했다.

```bash
uv run python docs/assembly/tools/verify_screws.py docs/assembly/data/screws.json docs/assembly/data/verify.json   # 약 2분
```

## 1. 기하 검증 — 가상 나사를 실제 메시에 넣어 보기

`verify_screws.py`는 원본 메시 38종(전부 닫힌 메시)을 월드 좌표로 놓고, 나사마다 그 축을 따라 점을 찍어 부품 안/밖을 판정한다.

| 검사 | 내용 | 결과 |
|---|---|---|
| T1 통과 | 머리 ~ 탭 시작 구간에서 나사 외경이 재료에 걸리지 않음 | **126 / 126** |
| T2 물림 | 끝에서부터 같은 부품에 묻힌 길이 ≥ 2.5 mm (M2.5는 3 mm) | **122 / 126** (경계 4) |
| T3 바닥 | 막힌 구멍 바닥에 닿지 않음 | **126 / 126** |
| T4 머리 | 머리 자리에 다른 부품이 없음 | **126 / 126** |
| T5 공구 | 머리 뒤 25 mm 안에 그 시점에 이미 있는 부품이 없음 (조립 순서) | **123 / 126** |

측정 메모
- XL330 프레임 구멍(Ø2.0)과 출력물 파일럿 구멍(Ø2.05)은 메시에 나사 호칭경으로 그려져 있어서 외경 점이 재료에 닿지 않는다.
  이런 구멍 43개는 1.3r 링으로 **구멍 벽 길이**를 재서 물림을 판단했다 (`nominal_hole`).
- 길이 격자 0.25 mm라 측정 물림은 계산값보다 최대 0.3 mm 짧게 나온다.

## 2. 검증에서 찾아 고친 것

| # | 문제 | 원인 | 조치 |
|---|---|---|---|
| 1 | 무릎 나사 8개가 바닥을 뚫고(T3) 물림 2 mm로 나옴 | 수동으로 넣은 머리 위치가 카운터보어 바닥보다 0.85 mm 안쪽(|y| 36.8)이었고, 0° 자세에선 혼 구멍이 45° 어긋나 있음 | 머리 위치를 실측 |y| = 37.65 mm로 고침. 무릎을 45° 돌린 자세에서 검사 → 정강이 구멍 4개가 혼 구멍 4개와 **정확히 겹침** (호밍 −512 = −45° 재확인). M2×6 물림 3.2 mm, 바닥 여유 2.8 mm |
| 2 | 고관절 롤 서보 볼트(좌우 1개씩)의 공구가 power_support(15 mm)·배터리(20 mm)에 막힘 | 전원부를 5단계에서 먼저 달았음 | 전원부를 **새 8단계(롤·다리 연결 뒤)** 로 옮김 |
| 3 | 머리 요 혼 → neck_pitch 볼트 4개가 목 서보(6.5 mm)에 막힘 | 목에 단 뒤에 조이게 되어 있었음 | **11단계 책상 위 서브조립**: neck_pitch를 목에 달기 전에 요 혼을 먼저 고정 |
| 4 | 머리 롤 혼 → yaw_roll_motion 볼트 4개가 요 서보(4.5 mm)에 막힘 | 요 서보를 먼저 넣었음 | 11단계 순서 ① 롤 혼 → ② 요 서보 → ③ 요 혼 |
| 5 | 보드(Pi) → 얼굴판 M2.5 볼트가 머리 서보(17 mm)·motor_support(29 mm)에 막힘 | 얼굴판을 머리에 단 뒤 보드를 다는 순서 | 14단계: **보드를 얼굴판에 먼저** 고정한 뒤 머리에 장착 |
| 6 | 윗셸 ↔ 아래 셸 M2.5 볼트 2개가 부리 부품(3 mm)에 막힘 | 같은 단계에서 부리와 윗셸을 함께 조립 | 15단계 윗셸 → 16단계 부리로 분리 |
| 7 | 배선도에 IMU 브리지(ID 200)가 머리 가지에 있음 | 그림 오류 | 몸통 IMU로 고치고 위치(trunk_base 기준 X −21, Y 0, Z −15 mm, 모델의 `imu` site) 표기. 8단계 주의사항에도 추가 |
| 8 | 13단계 motor_support 볼트를 M2×6으로 적음 | 문구 오류 | 계산값대로 M2.5×6 ×4 |
| 9 | 머리 롤 서보와 부리 서보를 구분하지 못해 같은 단계에 묶임 | 렌더·검증이 (바디, 메시) 단위 | geom 단위로 구분 (`HEAD_ROLL_SERVO` geom 86, `MOUTH_SERVO` geom 78) |

결과: 조립 13단계 → **16단계**, PDF 21쪽 → **24쪽**. 나사 규격·수량은 그대로 (M2×6 83, M2×8 18, M2×5 10, M2×4 4, M2.5×6 11).

| 항목 | 내용 | 권장 |

## 5. 검증 도구가 하지 못하는 것

- 나사산 강도, 출력물 재질·적층 방향에 따른 물림 강도
- 케이블 경로, 서보 가동 범위 끝에서의 간섭
- 메시에 없는 체결(위 3절 표)
