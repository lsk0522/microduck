# 변경 기록 — 일반 서보 v1.0 (원본 Pollen Microduck 대비)

원본 기구학(관절 이름·축·부호·가동 범위·바디 구조)을 **1.5배**로 키우고, 서보를 MG996R / MG90S로 바꿔 내부 기구를 새로 설계했다.
기준: `plan-hobby-servo.md` (계획 대화), `cad/hobby_servo/reference_1.5x/joint_frames.csv`.

| 항목 | 원본 / 계획 | v1.0 | 이유 |
|---|---|---|---|
| 크기 | 25 cm | ×1.5 (관절 위치·셸 모두) | MG996R(40.7×19.7×42.9)이 원본 다리에 안 들어감 |
| 다리 10축 + 목 pitch | XL330 | MG996R ×11 | 계획대로 |

| 부리(mouth) 서보 | 계획: MG90S, 생략 가능 | **생략** | 정책이 쓰지 않음 (계획 문서 "생략 가능") |
