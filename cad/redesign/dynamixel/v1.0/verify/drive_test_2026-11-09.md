## 3. 버티는지 (MuJoCo)
- 서 있기 유지 토크 (`sim/check_model.py`, XL330 7.4 V 정지 0.77 N·m): STAND 최대 무릎 0.055 N·m(7 %), SIT 머리 pitch 0.258 N·m(34 %, 원본 같음) — 원본과 차이 ≤ 0.006 N·m
- 출력 부품 부피 합 원본 대비 −0.14 % (≈ −0.3 g) → 무게중심·토크 변화 없음
- 균형 제어 없이 서보 위치 제어만: 모델 기본 강성으로는 0.87 s 에 앞으로 넘어짐 (원본 0.85 s, 같음). 강성 2배면 새 모델은 섬(기울기 11°), 원본은 3.3 s 에 넘어짐. 4배 이상은 둘 다 섬 → 걷기·서기는 원작처럼 정책(RL) 필요
- 앉았다 일어서기·전 범위 무작위 동작에서 로봇 몸끼리 접촉: 원본과 같음 (`selfcol_sim.py`, `dyn_stand.py`)
