# 관절·충돌 시뮬·케이블 검증 (v1.0, 2026-11-03)

비교 기준: 같은 MJCF 운동학에 **새 부품 메시** vs **원본(cad/reference) 메시**. 원본에도 있는 문제는 "원본 동일"로 표시.

## 1. 관절 연결 (Fusion 어셈블리)
- 관절 14개 모두 PASS (축 방향 cos 1.0, 이탈 ≤ 0.0016 cm, 범위 MJCF와 동일, 자식 바디 일치). 바디 소속 15개 manifest와 불일치 0.

## 2. 충돌 — 정확 메시 (manifold 교집합 부피, `tools/verify_sim/freerange.py`, `interf_mf.py`)
관절 하나씩 0°에서 1° 간격으로 돌려 처음 닿는 각도 (다른 관절 0°):

| 관절 | 새 부품 | 원본 | 처음 닿는 곳 |
|---|---|---|---|
| hip_yaw (좌/우) | −18…30 / −30…18 | 동일 | 정강이 ↔ 배터리 |
| hip_roll, hip_pitch, neck_pitch, head_yaw | 전 범위 | 동일 | — |
| knee (좌/우) | −90…71 / −71…90 | 동일 | 발 ↔ hip_l |
| ankle | 0 (모델 접촉) | 동일 | XL330 혼 원판 ↔ 발목 브래킷 (혼 고정부, 실물 간섭 아님) |
| head_pitch | −66…90 | 동일 | 아래 머리 셸 ↔ 몸통 셸 |
| head_roll | −8…15 | 동일 | 롤 서보 ↔ yaw_roll_motion |

- **14개 관절 모두 새 부품과 원본의 무충돌 범위가 같다** → 재설계로 생긴 새 간섭 없음.
- 자세 187개(관절별 9단계 + 보행 범위 무작위 60개): 부피 증가가 가장 큰 것도 위 무충돌 범위 밖 자세(발목 −90° 등, 원본도 이미 667 mm³ 겹침).
- 관절각 0 조립 상태: 새 간섭 없음 (베어링 압입부 접촉 2곳은 원본과 같음).

## 3. 동역학 시뮬 (MuJoCo 3.17, scene_allcollisions, `dyn_stand.py`)
- STAND 키프레임 + 위치 제어만(정책 없음): 새 0.87 s / 원본 0.85 s에 넘어짐 — 원본도 같아서 모델 문제가 아니라 균형 정책이 필요한 것. 앉았다 일어서기도 동일.
- 동역학 중 로봇 몸끼리 접촉 0건 (새·원본 모두).
- 볼록 껍질(hull) 충돌로 전 범위 무작위 자세: 쌍별 최대 침투 깊이 새/원본 차이 ±2 mm 이내 (`sim_selfcollision_*.json`).

## 4. 케이블 (`cable_check.py`)
가정: XL330 커넥터 2개는 혼 반대쪽 끝면(OPERATION.md 3절과 같은 위치). 배선 순서 OPERATION.md 3절.
- 플러그 공간(끝면 앞 0–7 mm)·굽힘 공간(7–14 mm) 막힘 비율: 서보 15개 모두 원본과 같거나 차이 ≤ 4%p.
- 원본과 같은 주의점: 목 서보 30·31은 끝면이 서로 마주봐서(1 mm) 플러그 공간 82% 막힘 → 조립 때 30·31 케이블을 먼저 꽂고 목을 조립. 허벅지 12/22는 끝면 앞을 무릎 서보가 49% 가림 → 다리 조립 전에 꽂기.
- 빈 공간 최단 경로(1.5 mm 복셀, 케이블 반경 여유 1.5 mm): 다리·목 구간 6–123 mm, 동봉 X3P 180 mm로 충분. 
  **hat→34(부리 서보)** 는 머리 관절 끝자세에서 177 mm (원본도 177 mm) → 이 구간은 250 mm 케이블 권장.
- 경로 길이가 원본보다 길어진 구간: 10→11 +3.5 mm, 11→12 +4.4 mm (보강 셸 두께) — 여유 안.
