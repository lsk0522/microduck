- 재질: 알루미늄 **5052-H32** (대체 6061-T6). 레이저·워터젯, 공차 ±0.1, 거스러미 제거.
- DXF: mm, 외곽 닫힌 폴리라인(레이어 OUTLINE, 원호는 bulge), 원 구멍 CIRCLE·장공 폴리라인(레이어 HOLES), 치수·문자 없음.
- **Ø19 구멍은 키우지 말 것** (Ø18.6~19.4): 16×22×4 베어링 내륜(Ø18.06)은 피하고 외륜(Ø19.9) 면을 받친다. XL330 혼(Ø16)과 반경 여유 1.5 mm.
- M2 구멍 = XL330 프레임 관통 구멍(Ø2.0)과 동심 → 동봉 M2 탭볼트.
- 가공 검사: 모든 구멍 테두리 ≥ 1.5t, 웹 ≥ t, 안쪽 모서리 R ≥ 0.5 (`tools/make_plate_outputs.py`).
- 싼 대안: 1 mm 3종은 FR4 1.0 mm PCB 외곽 가공 가능.
- **주문은 사용자 확인 뒤** (트랙 미정).
